# SudokuFoss

SudokuFoss é um jogo de Sudoku desenvolvido como uma aplicação web leve em HTML, CSS e JavaScript. Ele possui um tabuleiro interativo, modo lápis, sistema de pontuação, dicas e tema personalizável.

## Como usar

- Abra `SudokuFoss.html` em um navegador moderno.
- Selecione a dificuldade desejada e comece a jogar.
- Use o teclado numérico na tela ou o teclado físico para inserir números.
- Pressione `Espaço` para alternar o modo lápis.

## Funcionalidades

- Geração de Sudoku com diferentes dificuldades
- Anotações no estilo lápis
- Dicas integradas
- Loja de temas e compra com moedas fictícias
- Tema claro/escuro e efeitos visuais
- Modal de vitória com resumo de tempo e pontuação
